# 观窗 1.1.0-preview2 · CK3 窗口外观布局公开预览

观窗是给 CK3 Mod 作者用的 Windows x64 外观布局工具。可以把已有游戏窗口的 `.gui` 打开成整窗网页，调整位置、尺寸、文字和纹理，再导出完整的 `.gui`。也可以从自己设计的本地 HTML 出发，把指定画布下一个可见状态的布局转换成原生窗口和配套 DDS 贴图。

观窗会重新读取生成的文件，与网页对照。通过范围内检查的布局会输出到 `candidate`；需要人工核对的区域会写入记录，草稿放在 `待复核`；发现确定的错位、文字裁切或贴图错误时，只留下诊断和对照图。游戏内的按钮行为由 Mod 作者接入。

**第一次使用**  
下载附件中的 Windows x64 ZIP，完整解压，双击 `Guanchuang.exe`。网页转换使用本机 Edge 或 Chrome。可以先打开随包的 `示例/外观草图.html` 体验从网页生成原生窗口。

这是公开预览版。固定画布的浏览器布局对照、导出和回读已实测。本版从独立网页新生成的窗口仍待 CK3 实机复验。欢迎试用者反馈时注明窗口尺寸、界面缩放和网页状态，并附上 `visual-audit.json` 与对应截图。
