# 观窗 1.1.0-preview2 · AI 辅助制作 CK3 窗口外观

观窗是一款 **AI 辅助工具**，用来在 Windows 上制作《十字军之王 III》（CK3）的原生窗口外观。推荐在 Codex 里用 GPT 根据你的要求制作 HTML 草图，DeepSeek（DS）等能运行本地命令的助手也可使用。观窗把指定画布和状态下的外观转换为 `.gui` 和配套的 DDS 贴图。已有的游戏窗口也能打开成整窗网页，调整位置、尺寸、文字和纹理，再导出完整 `.gui`。

观窗会重新读取生成的文件，与网页对照。通过检查的布局放在 `candidate`。需要人工看图的草稿放在 `待复核`，并注明具体区域。发现确定的错位、文字裁切或贴图错误时，工具会生成诊断和对照图供助手定位。游戏内的按钮行为由 Mod 作者接入。

**第一次使用**  
使用本地 AI 助手时，把仓库首页的指令发给它，它会通过 Python skill 调用观窗。自己用图形界面时，下载 Windows x64 ZIP，完整解压后双击 `Guanchuang.exe`。网页转换使用本机 Edge 或 Chrome。[首页使用方式与可复制指令](https://github.com/apo-so/guanchuang#使用方式)

这是公开预览版。固定画布的浏览器布局对照、导出和回读已实测。本版从独立网页新生成的窗口仍待 CK3 实机复验。欢迎试用者反馈时注明窗口尺寸、界面缩放和网页状态，并附上 `visual-audit.json` 与对应截图。
